## 调查与实现边界

用户明确保留顶部右侧现有实时/上传模式切换，位置、样式、文案与逻辑全部不改。

网页版 Link 按钮及握手的当日源码证据见 docs/design/mindplus-link-web-boundary.md；不将超时的官网动态场景当作成功运行证据。临时profile删除被自动审批拒绝，目录暂留并有记录，不将其写成完全清理。

- 对照项目操作、积木编辑、主控/模块扩展、代码区、串口和编译上传；区分已实现、行为差异、真实缺失和尚未验证。
- 先由两侧设计提出真实差异，主控冻结统一契约后开发，最后由独立 Sol low 验收。设计/开发使用 Sol ultra。
- 不将桌面原生端口能力等同于浏览器权限；不通过后端代理获取远程服务器 USB，也不按 VID/PID 或枚举顺序猜测浏览器端口与 COM 端口对应。
- 第一阶段匿名项目存储与不接登录/Python大后端/SQL/OSS的边界继续保持。桌面专属功能在对照中列出，不静默引入另一套运行时、账户或云服务。
- 本轮不访问COM3、不执行烧录、不启停用户5173/3001/3002服务；实际硬件验证与隔离浏览器验证分开记录。
