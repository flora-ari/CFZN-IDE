## 聚焦验收

1. 进入真实自定义模块工作台，四种形状新增各打开 540px 弹窗，先取消再确认。验证原生声明块形状、主题色、初始缩放、五按钮与原生字段内删除。缩窄窗口并使用键盘进入控件，连续开关后继续编辑作品。
2. 在同一块插入三个不同类型参数及设备下拉，为每个设置不同默认值。删除中间参数、改名，再确认及重开，剩余默认值与代码占位符正确。覆盖已有字段类型、最后一片段、默认项切换、长标签、字面百分号、重复 ID、负数与 0。对在编辑框中尚未失焦的最后一次修改分别测试 OK、X、取消和 Escape。
3. 块逻辑、公共代码和库搜索独立打开。验证实际 Monaco、显式示例、头文件两区域切换、取消丢弃、保存后重新打开、按名称和版本精准提交依赖、搜索失败重试及关闭请求取消。生成预览在隔离区真实拖拽，作品积木、撤销/重做、选中和上传编辑器内容维持进入前状态。
4. 保存并将新版本添加到作品，确认真实工具箱文本和数字影子、布尔插口、三个引脚来源、带子块生成与空槽回退。另页恢复已有旧模块字段和新模块块图。验证运行阶段只使用当前板引脚，未准备好时提示缺少引脚信息。核对 VM/Blockly 固定上游字节。源码核对阶段无运行验收结果。
