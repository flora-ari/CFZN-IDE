# v0.7 独立验收要点

2026-11-12，主控。先开发冻结，再派Sol low；本文件是验收要求，不是执行结果。真实隔离Vite dev与静态dist分别检查；产品仅重用现有项目API与本机能力API。顶部模式切换保持现有位置/文案/样式/逻辑。

## 保存

实际按键验证父页面与iframe所属焦点，首次POST/后续PUT与一次按键一次保存。正在编辑标题、注释、积木字段或手稿时，最后输入应进入归档；验证输入焦点/选区不会在用户切走后被抢回。重复keydown、组合输入、Alt/Shift、busy和模态不产生额外写入，Ctrl+F/Z/Y等原行为保留。真实412依旧提供恢复/另存为，并保全完整作品/素材/手稿、dirty及revision。与保存按钮同一路由，不用截图宣称API成功。

## 积木搜索

通过实际搜索入口输入中文、英文及无结果查询，期望依据真实原生类别/积木而不是产品索引内部数组。覆盖Scratch、当前主控、加载模块、变量/列表及有参数自制过程；重复opcode不同语义模板保留，shadow/菜单不单列。真正鼠标拖出结果，核对字段、shadow、过程参数和上传参数敏感生成，禁用上传块在编程模式不能因搜索而启用。

目标/主控/模块/模式/语言/变量或过程更新后结果符合当前集合，不出现旧异步结果或被移除模块。清除、Escape、关闭、空查询和被移除原类别的回退均可达，不丢原分类；关闭恢复合理焦点/滚动。反复查询/索引前后GET_STATE、完整块图/字段/监视器/素材/手稿保持，不停止正在运行的纯舞台程序。独立核对索引实例不会污染原生工作区/undo，VM及Blockly上游字节不变，新hook仅GUI。

## 服务和终端

使用明确模拟的能力/端口服务，覆盖在线、网络离线、错误协议/结构、缺core、仅ports失败、有界超时及乱序旧响应。服务状态不改WebSerial连接、显式profile/OS端口、源码、dirty或作业状态，不产生build/upload。现有作业的网络中断与取消/占有语义不得因健康检查改变。

模拟串口通过正常连接/收发入口建立；写入成功后才记TX。切模式/隐藏/locale重挂后日志、发送草稿、收发格式、行尾与暂停状态保留，隐藏期间普通RX按既有限额记录，订阅和reader/writer仍唯一。保留UTF-8跨块、CRLF、session隔离、显式暂停丢弃与清空语义，协议占用不冒充普通终端。不得把模拟端口称为COM3实机证明。

## 已加载筛选和保留范围

实际扩展页三大分类的已加载筛选取真实状态，默认全部；两个主控入口同一过滤。类型/关键词/兼容取交集，选中与真正移除后结果即时变化，取消勾选不卸载，空结果清除完整恢复。筛选不dirty，使用中引用/依赖仍拒绝移除，焦点回退正常。20项目录、五按钮与保存状态、顶部模式按钮均保持。

## 主控复核补充

开发期静态复核定位过原生 toolBoxFinish 事件触发重复索引、headless 过程 shadow/disabled 的 SVG 调用，以及异步 dispose 隐藏全局字段编辑器的问题。实现已改为每个 GUI 绑定复用隔离 workspace，只调整索引用副本、原始结果 XML 不变；同步 Events 守卫不得跨 await，不得 clearUndo 污染主工作区。独立测试须核对运行结果，不把此处源码结论当通过证据。

保存后的焦点恢复还需检查 document.hasFocus，避免切到父页面后被 iframe 抢回。编译弹框属于外部状态订阅，需覆盖服务响应早于 effect 订阅安装的窗口：订阅后应读取最新 snapshot，不能永远停在 checking。相关主控建议已交前端；最终是否完成以冻结源码和独立报告为准。
