# 默认浏览器串口与单步新设备连接

2026-11-24。约一页最小前端提案，供主控冻结；本轮只写设计。

**目标：支持 Web Serial 时默认浏览器来源，自动列出已有许可；首次/新设备只有“连接新设备”一个入口，选择后直接连接。** 用户已同意产品使用浏览器串口，浏览器自身的首次设备选择仍由真实点击触发，不在页面加载时调用 requestPort。[Chrome 官方说明](https://developer.chrome.com/docs/capabilities/serial/)

## 已定位的多余步骤

[SerialDevicePanel](../../apps/web/src/serial-device-panel.ts#L20) 当前默认 local，authorize() 只调用 chooseSerialPort()，选完还要点设备行连接。[connection-modal.ts](../../apps/web/src/connection-modal.ts) 始终在顶部显示本机状态，并单独展示“授权浏览器串口”。[SerialSources.getPorts](../../apps/web/src/local-serial.ts#L290) 等待本机与浏览器两路完成；面板 refresh 又同时检测本机编译能力，因此未运行的 3002 服务会拖慢已有浏览器许可的出现。

## 最小交互与挂点

1. **默认来源。** Panel 初始化一次：sources.browser 可用选 browser，unsupported 才选 local。两个来源入口简化为“浏览器串口”“本机直连”，浏览器行副标题改为“浏览器串口”。保留用户随后手动选择；刷新、重新开面板和后台状态变化不强制切回默认，不改变已有连接。
2. **打开即可列出现有许可。** 面板挂载自动 getPorts，只读取已有授权，不弹选择框、不自动打开第一项。刷新按当前来源执行：浏览器路径独立读取并发布浏览器对象，不启动或等待 local.getPorts、hardware.refresh 的本机 HTTP 检测；SerialSources 增来源刷新策略，保留另一来源缓存/活动对象。本机检测继续在本机来源或用户明确检测时执行，不改已活动本机会话的续约。不能只隐藏错误文字而继续等待 3002 超时。
3. **一个新设备入口。** 移除独立“授权浏览器串口”按钮及授权后再选行的步骤，以“连接新设备”代替。增加面板内部 connectNewDevice：在原始 click 栈完成现有守卫并直接调用 hardware.chooseSerialPort()；取得非空 id 后接 panel.activate(id)，复用原生 connect 和单会话事务。requestPort 前无 await、HTTP、扫描、定时器或效果回调。已有行仍直接点最右“连接”，不重新申请许可。新行用默认 115200，选中已有对象时取该行保存/编辑的设置，不继承另一行速率；同目标同设置保持现有 no-op。
4. **取消与失败。** choose 的 null 不进入 activate。取消/拒绝不关闭旧端口，不清其设置、偏好或活动状态，不自动再次弹框；授权错误尚无所属行时显示紧凑面板反馈，连接错误归对应行。首次选择完成后的连接仍受当时守卫检查，任务状态变化时不抢占。单一 reader/writer、失败恢复、编译/上传/协议及模式互斥保持现有事务。
5. **按来源显示信息。** 浏览器来源隐藏未活动的本机状态面板，不让 Failed to fetch 占据顶部或禁用浏览器连接；本机来源继续显示能力、更新要求及真实 OS 行。另一来源已有活动连接时保留活动行及必要释放/状态未知提示，不隐藏真实占用。本机连接入口继续可用，两个来源身份仍分开，不推测 COM 映射。浏览器空列表写“尚无已授权设备，点击连接新设备”，已有行时无需单独授权；不支持时说明可用本机直连。

五列顺序继续为 **设备名称｜端口｜波特率｜状态｜操作**；连接/断开/切换/应用仍在最右操作区，窄屏底部右对齐。每行偏好、固定标题关闭与正文滚动复用已验收面板。HTTP、后端、依赖、VM/Blockly 和作品格式无需变更；此前契约仅需主控更新“默认来源/首次入口/来源刷新”三项。

## 聚焦验收

- 已有两个浏览器许可、3002 未运行：打开立即列行，requestPort/open 调用数均为 0，无本机报错挡面板；点某行只打开该行。
- “连接新设备”一次点击同步触发 requestPort，选择成功只调用一次连接；取消、拒绝和重复点击不破坏旧连接。权限选择期间开始其他任务时，接续连接重新检查守卫。
- unsupported 默认 local；用户切来源、刷新、重开面板均不重置偏好、不自动切换连接。授权 ID 与 OS 端口不合并，非活动行波特率不被覆盖。
- 浏览器列表读取失败显示其真实错误；无独立授权按钮，无“授权成功后再点行”的必要步骤。复测最右操作完整、窄屏和原有释放/上传守卫。

本次没有修改业务源码或运行浏览器、服务、实体串口。
