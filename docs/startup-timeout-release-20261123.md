## 问题与改动

首页和 API 初始测得 TTFB 约 40ms，服务器负载、可用内存和磁盘正常。实际阻塞主要在 GUI 静态脚本：此前 22,663,813 字节未启用压缩，前端从 iframe 创建即开始的 45 秒计时覆盖整个下载。超时提示出现后，晚到的 READY 没有清除旧错误。

本次在打包阶段为有效压缩的文本静态文件生成 gzip 副本，保留原始内容和文件时间，仅在 IDE 站点开启 gzip/gzip_static、Vary 和 ETag，API 关闭本次压缩。稳定资源 URL 沿用 no-cache 条件校验，构建哈希资源继续长缓存。没有修改 VM/Blockly 模块字节。

前端 45 秒仅提示慢加载，真实加载失败或 180 秒未就绪才提供手动重试；晚到 READY 清除本次启动状态，业务提示独立保留。初次尚未就绪可重建 iframe 和 bridge，旧监听与计时器被释放，已就绪的作品不能被启动重试重载。关键脚本前的错误监听会显示具体加载失败原因。左上角 Logo 正常和溢出状态均为“CCraft 官网”原生链接，支持 Tab/Enter，新标签页打开官网。
