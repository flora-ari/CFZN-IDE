# 串口实机验收

本阶段 Web Serial 终端用于字节收发。OpenBlock 的设备积木控制、编译和固件烧录需要另行接入板卡协议/OpenBlock Link，不属于本轮终端验收。

## 操作

1. 在本机 Chrome 或 Edge 打开 `http://127.0.0.1:5173`，打开串口终端；连接运行已知回显程序的设备。
2. 设置与固件一致的波特率，点击连接，在浏览器选择器中选择该设备。记录连接状态。
3. 文本模式发送已知字符串（例如 `CFZN test`），分别验证不换行 / LF / CRLF；核对收到的字节和固件行为。
4. HEX 模式发送已知字节（例如 `00 7F 80 FF`），切换接收显示，核对数据；若固件只处理文本，则使用专用回显程序完成此项。
5. 断开并重新连接；在接收中拔出设备，确认状态恢复且可以重新连接；同时验证项目编辑与保存仍可使用。
