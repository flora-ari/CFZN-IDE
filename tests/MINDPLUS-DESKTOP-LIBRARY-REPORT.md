## 项目保存与原字节核对

- 两个环境各保存一个独立项目。保存返回 `201`、`ETag: "1"`。同一项目的内容接口返回 `200`、`ETag: "1"` 和 `.ob` 下载响应。提交表单内的文件、HTTP 下载和由磁盘元数据指向的归档逐字节相同。
- 已保存作品切换分类、类型、搜索和勾选项前后，桥接快照完全一致，包含 `documentId`、`editVersion` 和 `dirty`。项目写请求仍只有首次 POST，磁盘元数据和归档原字节一致。
- 另开空白浏览器上下文后点“打开”。内容请求携带 `If-Match: "1"`，下载哈希与原归档一致。恢复保留主控 `arduinoUno`、上传模式、模块 `activateBuzzer`，以及真实积木 ID、连接关系和 5 项素材内容。恢复后再次序列化时两个 SVG 的 ZIP 条目名发生变化。按作品目标、素材名称和顺序配对后，素材 SHA-256 均相同。
- 从锁定的上游 OpenBlock GUI 压缩包提取模块并逐字节独立比对，共 178 个 VM 模块和 15 个 Blockly 模块匹配。开发与生产的 vendored GUI 文件也逐字节相同。冻结编辑器入口在执行前后的 SHA-256 均为 `6d327c831bd74e211dd8c04e27dafbf4ce20bfebbb61a1bc8e624796288db36c`。
